# corda-bootstrap

![Version: 0.1.0](https://img.shields.io/badge/Version-0.1.0-informational?style=flat-square) ![Type: application](https://img.shields.io/badge/Type-application-informational?style=flat-square) ![AppVersion: 4.14](https://img.shields.io/badge/AppVersion-4.14-informational?style=flat-square)

One shot Kubernetes Job that bootstraps a Corda OS 4.x network: runs the Corda network bootstrapper to generate node certificates, network parameters and peer NodeInfo files, then publishes all outputs as Kubernetes Secrets and a ConfigMap so the corda-node releases can start. Deploy this chart first via Helmfile (it is a needs dependency for every node release).

**Homepage:** <https://github.com/acmecorp/corda-platform>
